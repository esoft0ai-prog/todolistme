# Building Finora for Android

Finora uses Expo's **Continuous Native Generation**: the `android/` project is generated from `app.json` and `plugins/withFinoraAndroid.js` by `npx expo prebuild`. Never hand-edit `android/`; change the config and regenerate. This keeps the native project reproducible and upgradeable.

## 1. Requirements

| Tool | Version |
|---|---|
| Node.js | 20 or 22 |
| JDK | 17 (React Native's Gradle plugin requests a Java 17 toolchain) |
| Android SDK | Platform **36**, Build-Tools **36.0.0**, **NDK 27.1.12297006**, CMake 3.22.1 or newer, Platform-Tools |
| Disk / RAM | ~6 GB free, 8 GB RAM recommended |
| Network | `registry.npmjs.org`, `services.gradle.org`, `repo.maven.apache.org`, **`dl.google.com` / `maven.google.com`** (Android Gradle Plugin & AndroidX), `plugins.gradle.org` |

Set `ANDROID_HOME` (or create `android/local.properties` with `sdk.dir=/path/to/sdk` after prebuild).

## 2. Install & generate

```bash
npm install
npm run typecheck && npm test          # optional but recommended
npx expo prebuild -p android --clean    # (re)creates android/ from app.json + plugins/
```

## 3. Debug build

```bash
cd android
./gradlew assembleDebug
```

Output: `android/app/build/outputs/apk/debug/Finora-1.0.0-debug.apk`

A debug build is debuggable and loads JavaScript from the Metro dev server — start it with `npx expo start` (or simply use `npx expo run:android`, which builds, installs and starts Metro). Use it for development, not for distribution.

## 4. Release build (standalone, installable APK)

### 4.1 Create a signing key (once — keep it forever)

```bash
keytool -genkeypair -v -storetype PKCS12 -keystore finora-release.keystore \
  -alias finora -keyalg RSA -keysize 4096 -validity 10000
```

Store the keystore and passwords somewhere safe (password manager + offline copy). **Every future update must be signed with this same key**, otherwise Android refuses to install it over the existing app.

### 4.2 Point Gradle at the key

Create `android/keystore.properties` (git-ignored — never commit it):

```properties
storeFile=/absolute/path/to/finora-release.keystore
storePassword=********
keyAlias=finora
keyPassword=********
```

…or export `FINORA_KEYSTORE_FILE`, `FINORA_KEYSTORE_PASSWORD`, `FINORA_KEY_ALIAS`, `FINORA_KEY_PASSWORD`. Without a key the build prints a warning and signs with the debug key (testing only — the React Native debug key is public, so never distribute such an APK).

Because `android/` is regenerated by prebuild, keep `keystore.properties` somewhere else and copy it in (or use the environment variables) after `expo prebuild --clean`.

### 4.3 Build

```bash
cd android
./gradlew assembleRelease
```

### 4.4 Where is the APK?

```
android/app/build/outputs/apk/release/Finora-1.0.0-release.apk
```

That single file is the app. Copy it anywhere. The R8 mapping file (for de-obfuscating crash stack traces) is at `android/app/build/outputs/mapping/release/mapping.txt` — keep it with each release.

### 4.5 Verify (optional)

```bash
BT=$ANDROID_HOME/build-tools/36.0.0
$BT/apksigner verify --print-certs android/app/build/outputs/apk/release/Finora-1.0.0-release.apk
$BT/aapt2 dump permissions android/app/build/outputs/apk/release/Finora-1.0.0-release.apk   # must NOT list INTERNET
$BT/aapt2 dump badging android/app/build/outputs/apk/release/Finora-1.0.0-release.apk | head -3
```

## 5. Building on GitHub (no local Android setup needed)

`.github/workflows/android-apk.yml` builds the release APK on every push: typecheck → tests → prebuild → `assembleRelease` → verifies there is no INTERNET permission → uploads the APK (with SHA-256 and R8 mapping) as a workflow artifact. Pushing a tag like `v1.0.1` also attaches the APK to a **GitHub Release**.

Add repository secrets for proper signing: `ANDROID_KEYSTORE_BASE64` (`base64 -w0 finora-release.keystore`), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`.

## 6. Configuration reference

| What | Where |
|---|---|
| App name, version, package id (`com.finora.app`) | `app.json` → `expo.name`, `expo.version`, `expo.android.package` |
| Version code | `app.json` → `expo.android.versionCode` (increase by 1 for every release you distribute) |
| Icons | `assets/icon.png` (legacy), `assets/android-icon-{foreground,background,monochrome}.png` (adaptive, Android 8+/13 themed) |
| Splash screen | `expo-splash-screen` plugin in `app.json` (`assets/splash-icon.png`, background `#070A14`) |
| Notification icon/colour | `expo-notifications` plugin (`assets/notification-icon.png`, `#7C8CFF`) |
| SDK levels | `expo-build-properties`: minSdk 24 (Android 7.0), compile/target 36 |
| ABIs | `expo-build-properties.buildArchs`: `armeabi-v7a`, `arm64-v8a` (add `x86_64` for emulators) |
| R8 / ProGuard | `enableMinifyInReleaseBuilds` + `enableShrinkResourcesInReleaseBuilds`; extra keep rules appended to `android/app/proguard-rules.pro` by the Finora plugin (SQLCipher JNI classes, notification classes that are Java-serialised) |
| Database encryption | `expo-sqlite` plugin `useSQLCipher: true` |
| Permissions | `app.json` → `android.permissions` / `android.blockedPermissions`; exact-alarm permissions and the release-only removal of `INTERNET`/`ACCESS_NETWORK_STATE` come from `plugins/withFinoraAndroid.js` |
| Backup rules | `plugins/withFinoraAndroid.js` → `res/xml/finora_data_extraction_rules.xml`, `allowBackup=false` |
| Signing | `plugins/withFinoraAndroid.js` (reads `android/keystore.properties` / env vars) |
| APK file name | `plugins/withFinoraAndroid.js` → `Finora-<version>-<buildType>.apk` |
| Engine | Hermes, New Architecture (`gradle.properties`, generated) |

### Versioning a new release

1. Bump `expo.version` (e.g. `1.0.1`) and `expo.android.versionCode` (e.g. `2`) in `app.json`.
2. `npx expo prebuild -p android --clean` → copy `keystore.properties` → `./gradlew assembleRelease`.
3. Distribute `Finora-1.0.1-release.apk`. Users install it over the old version; their data is kept.

## 7. Distributing without Google Play

The APK can be shared any way you like: WhatsApp, Telegram, Bluetooth/Nearby Share, USB cable, email, Google Drive/Dropbox link, your website, or GitHub Releases. Publish the SHA-256 checksum alongside it so people can verify the file.

**Installing a sideloaded APK (Android 8+):**

1. Open the APK from Files/Downloads/WhatsApp/Chrome.
2. Android asks to allow that app to *Install unknown apps* → **Settings → Allow from this source** → back.
3. **Install**. If Google Play Protect warns about an unknown developer, choose **More details → Install anyway**. (Optionally *Send for analysis*.)
4. Open Finora.

On Android 7 the switch is global: *Settings → Security → Unknown sources*.

Some phones (MIUI/HyperOS, some Tecno/Infinix builds) additionally require disabling "MIUI optimisation"/"Pure mode" style protections or confirming a second prompt.

## 8. Troubleshooting builds

| Error | Fix |
|---|---|
| `Cannot find a Java installation … languageVersion=17` | Install JDK 17 (`sudo apt install openjdk-17-jdk-headless` or Temurin 17) and/or set `JAVA_HOME` to it. |
| `Could not GET https://dl.google.com/...` 403 / timeout | Your network blocks Google's Maven repository. Allow `dl.google.com` and `maven.google.com`, or build on GitHub Actions. |
| `Received status code 429 from server` (Maven Central) | Rate limited; retry later or add a mirror such as `https://maven-central.storage-download.googleapis.com/maven2/` via a Gradle init script. |
| `NDK not configured` / wrong NDK | `sdkmanager "ndk;27.1.12297006"`. |
| `SDK location not found` | `export ANDROID_HOME=…` or `android/local.properties`. |
| `Execution failed for task ':app:mergeReleaseResources'` after changing icons | `npx expo prebuild -p android --clean`. |
| Out of memory | Raise `org.gradle.jvmargs` in `android/gradle.properties` (e.g. `-Xmx4096m`). |
| Release APK crashes but debug works | Check `adb logcat`; add a keep rule in `plugins/withFinoraAndroid.js` for any class reported as missing, regenerate. |
